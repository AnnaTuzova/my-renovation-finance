# Мой ремонт — версия 1.0

Небольшое автономное приложение для Android (PWA). Без серверов, аккаунтов и отслеживания счетов.

## Возможности
- Категории: создание, изменение, удаление пустых категорий.
- Расходы: добавление, изменение, удаление, дата и комментарий.
- Суммы по категориям за выбранный месяц и общий итог.
- Все операции по датам.
- Статистика по категориям и месяцам.
- Экспорт CSV (разделитель `;`, UTF-8 с BOM) и резервная копия JSON с восстановлением.
- Локальная база IndexedDB и автономный режим после первой загрузки.

## Запуск на компьютере

Установи Python 3.9+ и в каталоге проекта запусти:

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`.

## Установка на Android

Для полноценной установки PWA сайт должен быть доступен по HTTPS. Размести содержимое папки на статическом HTTPS-хостинге (например, GitHub Pages). Открой адрес на Android в Chrome, затем меню ⋮ → «Добавить на главный экран» → «Установить приложение» (названия пунктов могут отличаться).

После первой загрузки приложение доступно без интернета. Данные хранятся в памяти браузера **на этом устройстве**, не синхронизируются между телефонами. Не очищай данные сайта без резервной копии JSON. CSV — только для анализа, восстановление выполняется из JSON.

### Быстрая публикация через GitHub Pages
1. Создай публичный репозиторий на GitHub.
2. Загрузи содержимое этой папки в корень репозитория.
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root).
4. Дождись адреса `https://<имя>.github.io/<репозиторий>/`, открой его на телефоне.

Публикуется только исходный код приложения, **не расходы**: расходы остаются в локальной базе телефона.

## Структура
- `index.html` — интерфейс и стили.
- `app.js` — логика, база данных, экспорт/импорт.
- `sw.js` — автономное кэширование.
- `manifest.webmanifest` и `icon.svg` — установка и значок.

## Ограничения первой версии
Валюта — рубли. Нет синхронизации между устройствами и импорта CSV. Перед обновлением приложения рекомендуется сохранить резервную копию JSON.
